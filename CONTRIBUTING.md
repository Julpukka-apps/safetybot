# Contributing

SafetyBot is under development. The repository stays private.

1. Run `npm install`, then `npm run dev`. The dev server is on port 8082.
2. Do not commit `.env`, `.env.local`, `data/`, or `credentials.json`.
3. Do not commit real reports or photos. Screenshots in `docs/screenshots/` use dummy text.
4. Keep worker capture, draft, and done behavior unchanged unless the owner asks for that change.
5. `npm run build` must still succeed before a change is pushed.

There is no CI workflow in this repo. Do not add one unless the owner asks.
